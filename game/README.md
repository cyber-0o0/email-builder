# Сброс и Снос (Drop & Smash)

HTML5-игра для Яндекс Игр. Мы бригада сноса: по заказам жителей убираем старые, аварийные и ненужные постройки, чтобы на их месте построить новое (огород, парк, каток, телескоп...). Перед уровнем заказчик объясняет, зачем нужен снос, а после победы показано, что появится на этом месте.

Контент намеренно безобидный: никакого оружия, людей, животных, религиозных и исторических объектов.

## Что внутри

- **30 разрушаемых целей** в 5 мирах (Деревня, Город, Пустыня, Ледяные земли, Луна). Каждая шестая цель — босс. Сюжетные тексты лежат в `src/js/story.js`. После 30-го уровня цели идут по кругу с ростом прочности (бесконечный режим).
- **17 предметов**: камень, кирпич, шар для боулинга, фейерверк, наковальня, пианино, хлопушка, ведро слизи, бур, резиновая уточка, ледяная бомба, молния, гиря 16 т, метеорит, солнечная лупа, космический пылесос, астероид.
- **Разрушение**: цель разбивается на ячейки Вороного. Ячейки трескаются, откалываются и разлетаются обломками с физикой твёрдого тела (вращение, трение, отскок, раскол при падении). Если часть конструкции теряет связь с землёй, она обрушивается целиком.
- **26 материалов**: дерево, кирпич, камень, бетон, стекло, лёд, металл, золото (больше монет), кристалл, ящики с фейерверками (цепные салюты) и другие. У каждого свой звук, своя текстура и свои частицы.
- **Отклик**: тряска камеры, стоп-кадр и замедление на сильных ударах, вспышки, ударные волны, вибрация, комбо, криты, летящие монеты.
- **Прогрессия**: улучшения предметов, 5 глобальных улучшений (сила, жадность, перезарядка, точность, дрон-помощник), бонус за скорость, x2 награды за рекламу.
- Весь звук и музыка синтезируются через WebAudio, а текстуры генерируются процедурно. Внешних файлов нет.
- Русский и английский языки, язык определяется через SDK.

## Сборка

```sh
node tools/build.js        # -> dist/index.html (один файл, шрифты встроены)
```

`tools/fetch-fonts.sh` заново скачивает шрифты (Russo One, Rubik), если они понадобятся.

## Загрузка в Яндекс Игры

1. `node tools/build.js`
2. Заархивируй содержимое папки `dist/` в zip (`index.html` должен лежать в корне архива).
3. Загрузи архив в консоли разработчика Яндекс Игр.

Интеграция SDK (`src/js/sdk.js`): `/sdk.js` загружается автоматически, а без SDK игра тоже работает.
- `LoadingAPI.ready()` после загрузки, `GameplayAPI.start/stop` во время уровня;
- облачные сохранения `player.setData/getData` (плюс копия в localStorage);
- полноэкранная реклама между уровнями (каждый второй уровень после 3-го), rewarded: x2 награды и монеты в мастерской;
- звук выключается при сворачивании вкладки и во время рекламы.

## Управление

Нажимай или кликай над целью, удержание сбрасывает предметы очередью. Клавиши `1`–`0` выбирают предмет, `Пробел` сбрасывает.

## Код

| Файл | Что делает |
|---|---|
| `src/js/core.js` | математика, полигоны, локализация, сохранения |
| `src/js/targets.js` | миры, 30 целей, кривая прочности и наград |
| `src/js/materials.js` | материалы и процедурные текстуры |
| `src/js/items.js` | предметы, их отрисовка, стоимость улучшений |
| `src/js/world.js` | разбиение на ячейки, связность, физика обломков |
| `src/js/game.js` | игровая логика, урон, эффекты, монеты, дрон |
| `src/js/render.js` | фоны миров, слой конструкции, кадр |
| `src/js/fx.js` | частицы и всплывающий текст |
| `src/js/audio.js` | синтез звуков и музыка |
| `src/js/ui.js` | интерфейс, мастерская, экраны |
